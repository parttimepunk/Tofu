# 重要决定

所有决定截至 2026-10-22；新决定追加日期、原因和影响，不把未选方案写成承诺。

| 决定 | 原因 / 影响 |
| --- | --- |
| 产品统一命名 Tofu，UI 英文 | 用户明确确认；文档允许中文，不能恢复早期命名 |
| Apple 风格、克制的绿色、System/Light/Dark | 用户逐轮确认；保持图片优先，媒体原色不被品牌色染色 |
| 图标采用暖灰米色底的写实白豆腐 | 用户选中柔角豆腐后，进一步明确选中 A 暖灰底；正式母版保存在源码中 |
| 跨设备采用可安装网页应用 | 个人使用、无付费开发者会员；避免原生 iPhone 签名流程；不等于 App Store / 分享扩展 |
| 独立免费 Tofu 后台 | 用户明确授权所属空间；不能共用其他 App 的后台、凭据或记录；不启用付费服务 |
| 私有原件 + 元数据快照 + CAS/三方合并 | 保留本地修改、账号隔离、显式处理并发冲突，避免整个库最后写入覆盖 |
| 首次连接需要确认 | 登录不等于同意上传未登录素材；明确复制本机数据选项 |
| 保留原生 Mac 版，库独立 | 不破坏已有本地数据；网页通过导出目录复制导入，不声称旧应用同步完成 |
| 网页支持混合文件拖入与自动分类 | 用户实用反馈需要截图/视频直接拖入；按 MIME/扩展名识别，不要求手选类别 |
| Vercel 发布到既有 Tofu 域名 | 用户已明确批准本轮发布；只发布 dist 静态文件，不上传个人数据或源码包 |
| 正式源码整理到 Documents/ChatGPT/Tofu | 用户本轮确认；原工作目录保留恢复点，仓库去除过期设计稿、机器缓存和安装包 |
| 公开源码，个人非商业用途许可 | 用户最新要求仅限个人、不允许商用；不采用 MIT；发布前移除私人配置，用户自行配置后台 |

## 公开发布补充

无后台配置时支持本地库并禁用云账号入口。同步通过 .env.local 配置使用者自己的 Supabase，CSP 同步生成；不附作者后台标识。源码与示例素材适用个人非商业用途许可，第三方依赖遵循其自身条款。

## 2026-10-29 — 浏览器扩展试用版

用户不接受书签配置，希望点开链接收集，因此新增一次安装的桌面 MV3 扩展方案。先支持小红书完整 DOM 图集与 Tofu 的显式选图/保存；不做全站抓取，不接管登录或验证。使用精确站点权限，不读取 Cookie；个人站点只写进被忽略的生成物。手机继续试用此前已签名的 Safari 快捷指令。用户先授权开发，随后明确确认安装到 Dia，并发布网站和源码；安装仅使用已说明的精确站点权限。
