# 公开仓库与隐私边界

本仓库按用户要求公开源码，采用个人非商业用途许可证，详见根目录 LICENSE；不是 MIT，也不宣称符合 OSI 开源定义。

## 可公开内容

当前源码、锁文件、数据库初始 SQL、生成的测试素材、现行说明和精选截图。图标为 AI 生成并经过选择确认；示例画面不是个人素材库。第三方依赖权利由对应许可证规定。

## 已移除 / 不提交

个人邮箱、电脑绝对路径、原部署域名/ID、原 Supabase 实例/公开客户端配置、凭据、历史安装包、私人工作档案。Git 忽略 outputs/、work/、依赖、构建、.vercel/、.env*（仅 .env.example 例外）、系统缓存与签名材料。

新建 Git 历史，不把旧工作区的暂存区或历史直接复制进公开仓库。提交使用 GitHub no-reply 邮箱，不写个人联系邮箱。GitHub 本身会显示仓库所属账号；这是公开平台身份，不等于匿名发布。

## 后台隔离

公开代码默认只使用本机库。使用者自己创建 Supabase，按照 development.md 配置 .env.local；生成 CSP 只允许所配置的后台。作者现有线上服务不在本次代码发布中重新部署或改变。

不要把私有生产配置、真实库 JSON、真实媒体、签名下载链接或会话作为 issue/测试内容上传。每次提交前审查 git status / diff，模式扫描不替代人工确认。
