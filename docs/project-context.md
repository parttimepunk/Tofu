# 项目背景

Tofu 是 用户 自用的创意素材库，目标是在 Mac 与 iPhone 上保存、浏览和重新组织互联网上看到的设计、海报、视频、音频及文字想法。

## 已确认的体验

- 素材类型：Images / Videos / Audio / Links / Notes。拖入后按文件媒体类型分类，不是 AI 内容识别。
- Date Added 按收藏时间浏览；Creative Order 保存独立的创意编排顺序，不互相覆盖。
- 合集、标签、收藏和搜索帮助长期整理；原件复制保存，可恢复移除。
- Apple 原生风格，英文 UI，完整浅色/深色视觉；桌面侧栏与图库，手机底部三项导航。
- 主色采用克制的玉绿色，正式图标采用暖灰米色背景和写实白豆腐。详见 [视觉说明](design.md)。

## 产品路线

采用可安装网页应用满足个人跨设备使用，不依赖付费 Apple Developer 会员。Mac 从 Safari 添加到 Dock，iPhone 添加到主屏幕；两端使用一个 Tofu 账号连接独立 Supabase 后台。

Swift 原生 Mac 本地版保留作为独立实现，不与网页库自动互通。旧库可以导出完整目录后，由网页设置复制导入。不得直接把正在使用的 JSON/媒体目录交给云盘覆盖同步。
